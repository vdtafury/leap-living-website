# Brand kit

Every LEAP LIVING lockup, full size, derived from the client's `docs/source-materials/leap-living-logo.png`.
Kept in the repository but **not published** with the site (moved out of `web/public/brand/`,
2026-11-18). The site serves only what it uses from `web/public/brand/`.

| Files | Use |
|---|---|
| `logo-horizontal-*.png` | Horizontal lockup (brand, teal, dark, white). The site serves resized copies of *brand* and *white* |
| `logo-stacked-*.png` | Stacked lockup. `logo-stacked-white.png` is read by `web/scripts/make-og-image.mjs` |
| `logo-mark-*.png`, `leap-icon-*.png` | Keyhole mark only |
| `leap-wordmark-*.png` | Wordmark only |
| `leap-living-logo-*.png` | Primary logo variants; `-original` is the untouched client file |
